# MeleeStartAttack — development record

**Author:** Babuni.dev

## Retrospective examination — 2026-10-26

A broader Vanilla WoW 1.12.1 start-attack quality-of-life addon for Warriors, Paladins and Shamans. MeleeStartAttack.lua detects supported actions from spell icons and optionally the real Attack action-bar slot, with fallback handling, per-class learned additions and /msa control commands. The addon extends the Warrior concept with class-specific whitelists and learning, while keeping attack-state behavior stable and ignoring client language.

The coding approach is evidenced by current source and public description, not by a complete dated original discussion. This session's AI contribution was analysis and organizing documentation. No gameplay changes or client tests were made; the original project direction remains attributed to Babuni.dev.
